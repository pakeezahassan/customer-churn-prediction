📞 COMMON ISSUES & SOLUTIONS
════════════════════════════

Issue: "Module not found"
Solution: Virtual environment not activated. Type:
   source venv/bin/activate (Mac/Linux)
   venv\Scripts\activate (Windows)

Issue: "telecom_churn.csv not found"
Solution: Dataset not in right place. Verify:
   data/telecom_churn.csv exists

Issue: "Port 5000 already in use"
Solution: Change port in app.py last line:
   app.run(port=5001)

Issue: "Git push rejected"
Solution: Make sure you created repo on GitHub first at github.com/new

Issue: Low accuracy
Solution: Check dataset loaded correctly, all features present
