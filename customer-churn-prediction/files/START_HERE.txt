================================================================================
WHAT THE API DOES (Optional - For Extra Polish)
================================================================================

Run: python src/app.py

Opens at: http://localhost:5000

Endpoints:
1. GET /          - Welcome page with documentation
2. GET /health    - Check if API is running
3. GET /info      - Model information
4. POST /predict  - Predict churn for one customer
5. POST /batch-predict - Predict for multiple customers

Example request:
curl -X POST http://localhost:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"features": [65, 2, 34.65, 45, 0, 0, 1, ...]}'

Example response:
{
  "prediction": 1,
  "prediction_label": "Will Churn",
  "probability_churn": 0.68,
  "confidence": 0.68
}

================================================================================
TROUBLESHOOTING
================================================================================

"Module not found" error
→ Check virtual environment is activated: (venv) should show in terminal

"telecom_churn.csv not found"
→ Download from Kaggle and place in data/ folder with exact name

"Port 5000 already in use"
→ Change app.py last line to: app.run(port=5001)

"Git push rejected"
→ Follow GITHUB_SETUP.md carefully, authenticate when prompted

"Model training too slow"
→ Normal - takes 1-2 minutes. Gradient Boosting needs time

"Low accuracy results"
→ Check dataset loaded correctly, verify features

Can't find files?
→ Check folder structure matches:
   src/train_churn_model.py
   src/app.py
   data/telecom_churn.csv
